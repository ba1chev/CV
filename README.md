## Building

**Overleaf:** create a new project, upload `main.tex` and compile with pdfLaTeX.

**Locally** (requires a TeX Live installation that includes the `roboto` font package):

```bash
pdflatex -jobname=yoan_baychev_cv main.tex
```

This produces `yoan_baychev_cv.pdf` directly, ready to commit.
